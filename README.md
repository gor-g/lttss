# For the developer

Currently tested python version : 3.12.2

To run the server for development :

```bash
cd path/to/repo && python -m lttss.cmd.lttss_cmd -r
```

To export the content of the clipboard

```bash
python -m lttss.cmd.lttss_cmd -e
```

To play it :

```bash
python -m lttss.cmd.lttss_cmd -p
```
